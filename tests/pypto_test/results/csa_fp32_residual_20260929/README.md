# FP32贯穿CSA残差流的私有实验

用户要求实测层间FP32潜力。比较同一46cec3a0算子基底，BF16与FP32残差输入/输出。
只去掉入口加宽/副本和HC_post残差转换、最终BF16舍入；RMS的512列归约顺序、attention的BF16舍入保持。
权重、KV/cache、量化和所有调度标志沿用当前实现。模型和生产入口未改。

两份完整包冻结到私有pkg后完成依赖图、候选CPU完整编译，再经auto提交。
首次任务task_20260929_215943_156967420945因队列命令未按单参数传入，在启动bash时退出2，未运行NPU用例。
修正提交方式后task_20260929_220058_15745896727运行相同冻结源码；失败任务未计为测量。

先128K/B16与8K/B24同卡A/B，后长档两侧各两个独立图重放泳道。
正式事件5预热20次，初始化时同值加宽不计入CSA；此计时代表上游已经提供FP32残差的条件。
性能之后核对首调用八类状态：输出舍入回BF16后比较，其余直接零容差比较。
还将输出接回输入再检查eager/graph与保护区，确认FP32低位被真正消费；连接用copy在计时外，非模型性能证据。
不把CSA收益外推完整Transformer/FFN/HCA或token/DSpark验收，先用两档决定是否值得扩大。
