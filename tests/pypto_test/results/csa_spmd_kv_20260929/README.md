# KV投影：有效N向扩核、流水检查及并发Compressor联动

基底e110a886，包括T96 O收尾48核+sync。性能版BF16残差、mode2/atomic0/det0、CANN9.2；
Native流程、精度版、权重布局、cache布局和工具链不变。只使用冻结私有pkg，source.json记录路径。
测试框架骨架来自上一轮冻结副本，所有vllm_ascend算子与共享代码重新从当前工作树复制。

## 为什么选择这组任务

先检查既有两窗早期投影泳道及生成orchestration，见overlap_review.json。
KV的完整K路径只用12 AIC（T96）或8 AIC（T144），与两个Compressor投影实际重叠：
首窗长档有22个Indexer Compressor worker和6个Attention Compressor worker的执行区间与KV包络相交，
短档分别22和23个；Indexer Q投影也有6/14个worker相交。QA投影已先完成，O收尾位于末端，不联动这两项。
相交计数是与整个KV组的包络相交，不能当成同一物理核同时执行或独立竞争根因证明。
生成编排确认kv_score_proj_0为Indexer Compressor，kv_score_proj为Attention Compressor，避免混淆同名任务。

## 分工与流水

- baseline：N128，M32/64主块、M16尾块，K512面板，完整4096维K，stage=2。
- kv_n64：只在atomic=0改N64。长档12→24 AIC，短档8→16；每份都有实际输出，不新增padding。
  M/K和外层K遍历次序不变，写区按M/N互斥。总B权重逻辑读取不变，A的N向重复读取翻倍。
- kv_n64_sync：上述KV组叠加sync_start。atomic=1仍N128且sync=False，避免原split-K任务组超24 AIC而死锁。
- kv_n64_linked：只额外给两个实际并发的Compressor投影开启sync，两者各24 AIC且均有工作，
  各自M/N/K tile、x复用、双累加器、stage=2、early和依赖都保持。没有全链批量开sync。

短档不盲目增加到24核：保留M64完整块和M16尾块时，当前M组只有2组。
若本轮仍暴露M尾部不均衡，再设计尾块独立分工；不先把主M块缩小破坏现有摊销。

**生成码的重要差异**：N64使AutoTileMatmul把L0 K128改为K256。源码K512/stage=2保持，
但不能称生成核体完全不变或只增加核数；Right由128×128变256×64，容量相同，Left的K面板变大。
两种M专化的Mat仍K512双缓冲，无TMOV；实际核时及八类状态还需设备验证。
pipeline_review.json列出Tile形状和静态指令位置；静态位置数不等于执行次数或流水效率。

## Native与上游参考

ops-nn19614968的matmul_v3_base_tiling.cpp：DoBasicTiling/DoSmallShapeTiling根据有效块数与small shape选基本块；
CalL1Tiling按容量计算depth和双缓冲stepKa/stepKb。借鉴的是有效块分配及L1/L0配合，不声称当前Native二进制用了N64。
pypto-lib2164563的DSpark KV采用N128/K256、split-K=4、atomic加和；当前性能版固定K采用M向分组与K512，
避免为填核新引入atomic、清零和浮点累加顺序变化。因此本轮优先尝试N向独占写分工。
既有KV NZ布局候选属于另一个尚未采用的方案，本轮不混入。

- 短档：task_20260929_234946_313544229541，8192/B24。

目标核的每worker时长、总core-us、启动分散、执行包络及关联任务分别统计，不能只看减半工作量后的单worker均值。
性能结束后复用保存状态检查八类完整张量、图重放及保护区；没有局部收益则不扩大七档或16卡。
完整CSA同时对开始/结束基线比较，长短按8:2；局部收益与完整区间收益区分。

均值与最大值分别报告相对开始/结束基线的变化，同样本数、不剔慢点，不揉成一个分数。
均值近似不变但最大值稳定下降的候选保留；单卡最大值不能替代EP16通信等待实测。

准备阶段的文本匹配首次未适配旧冻结包的同一行参数格式，尚未进入编译/上卡；

  包络均值51.700→43.000。完整CSA均值909.939，比前后基线924.343/916.268低1.558%/0.691%。
  **保留为短档场景候选**；尚未加入生产入口，后续用场景分支隔离，不能覆盖已退化的长档。
  最大948.000位于前后基线951.680/935.500之间，不能宣称已证明完整CSA稳定削峰。
