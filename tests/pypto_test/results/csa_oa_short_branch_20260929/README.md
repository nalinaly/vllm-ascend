因此不全局替换K256。本候选按用户要求在一套性能版算子内部选择，不在脚本按档位换实现。

任务在auto设备0完成退出0，八类完整跨版本状态零容差、图/保护区及16个官方窗口通过。

当前分支没有保住此前观测的短档收益，不认定K512普遍适合短历史，也不把旧数字拼成生产结果。
