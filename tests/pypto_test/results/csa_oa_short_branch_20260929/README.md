# O-A按实际长度与T分支，只保留短档K512候选

基线369ad2c1。前轮同为B16，长档O-A +6.663%、短档−8.638%，四窗范围各自不重叠；
因此不全局替换K256。本候选按用户要求在一套性能版算子内部选择，不在脚本按档位换实现。

| 输入条件 | NZ O-A L1 K | 依据 |
| --- | --- | --- |
| T=96且整批max(kv_seq_lens//4)≤8192 | 512 | 保留8K/B16候选 |
| T=96且存在更长请求 | 256 | 长档维持原策略 |
| 其他T，包括B4/B8/B24/B32 | 256 | 不外推未测形状 |
| ND | 256 | 原实现 |

阈值复用Indexer单leaf/多leaf既有分界8192压缩行，对应原序列约32K；
该范围仅代表分支规则，目前设备收益证据只有8K/B16，不能声称覆盖全部短历史。
判断使用实际seq_lens，混合请求按最长，不使用预分配cache容量或第一个请求猜测。
