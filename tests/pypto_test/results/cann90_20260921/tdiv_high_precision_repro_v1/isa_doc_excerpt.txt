46: 
47: `PrecisionType` has the following values available:
48: 
49: * `DivAlgorithm::DEFAULT`: Normal algorithm, faster but with lower precision.
50: * `DivAlgorithm::HIGH_PRECISION`: High precision algorithm, but slower.
51: 
52: ## Constraints
53: 
54: - **Implementation checks (A2A3)**:
55:     - `TileData::DType` must be one of: `half`, `float`.
56:     - Tile layout must be row-major (`TileData::isRowMajor`).
57:     - Tile location must be vector (`TileData::Loc == TileType::Vec`).
58:     - Static valid bounds: `TileData::ValidRow <= TileData::Rows` and `TileData::ValidCol <= TileData::Cols`.
59:     - Runtime: `src0`, `src1` and `dst` tiles should have the same `validRow/validCol`.
60: - **Implementation checks (A5)**:
61:     - `TileData::DType` must be one of: `int32_t`, `uint32_t`, `int64_t`, `uint64_t`, `float`, `int16_t`, `uint16_t`, `half`.
62:     - Tile layout must be row-major (`TileData::isRowMajor`).
63:     - Tile location must be vector (`TileData::Loc == TileType::Vec`).
64:     - Static valid bounds: `TileData::ValidRow <= TileData::Rows` and `TileData::ValidCol <= TileData::Cols`.
65:     - Runtime: `src0`, `src1` and `dst` tiles should have the same `validRow/validCol`.
66: - **Valid region**:
67:     - The op uses `dst.GetValidRow()` / `dst.GetValidCol()` as the iteration domain;.
68: - **Division-by-zero**:
69:     - Behavior is target-defined.
70: - **High Precision Algorithm**
71:     - Only available on A5, `PrecisionType` option is ignored on A3.
