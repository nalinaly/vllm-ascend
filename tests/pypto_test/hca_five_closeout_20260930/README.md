## 固定版本和计时口径

- 五点前版本 `55852cff`；最终默认 `29917c4e`。两者均含前一轮已落地的O-A流水。
- 冻结完整算子私有包后把Python源设只读。
  源码路径、工具链和七档见 [source.json](source.json)，任务原句柄见 [tasks.json](tasks.json)。
- CANN9.2beta2、正式DSV4 Flash 0731 W8A8权重第3层HCA、NZ2、BF16残差、atomic0、det0。
  单层使用合成历史，覆盖HC_pre+norm+HCA+HC_post；不是CSA/indexer区间。
- Native：`torch.compile(backend="npugraph_ex", dynamic=False)`，inplace/static/SuperKernel全开。
  每次均核实实际static编译结果、SuperKernel标记和安装包数；PTO关闭SuperKernel并核实dispatch。
- 每档绑定同一张卡，顺序是 **Native前测→旧PTO→最终PTO→Native后测**；
  七档在队列分配的七张不同卡上并行；同档内四pass串行。
  各侧独立新进程、先warmup5，再取30次PyTorch profiler内设备跨度。
  Native合并前后60个样本，旧/最终PTO各30个；不是同进程ABBA。
- 同层kernel首启至末完成的设备span，非host Event、非核占用求和、非整网forward。
  独立DFX泳道只用于调度分析，不混入正式耗时。所有表单位μs，顺序min/max/mean。
- 长档4项相对变化等权平均×0.8，短档3项等权平均×0.2；不按各档绝对时长加权。
