# Qwen3-14B Native 与 PyPTO 正式 profiling 对比

## 条件

- 单卡 TP1，device 0，BF16，权重/KV Cache 均为 ND。
- `CompilationMode.NONE` + `FULL_DECODE_ONLY`，capture size 为 1。
- 同一 prompt、greedy、固定 seed；先做一次不采集热身，再正式采集。
- 生成 4 个输出 token：首 token 来自 prefill，随后恰好 3 次 decode ACL Graph replay。
- `with_stack=false`、`record_shapes=false`、memory profiling 关闭。

## 总览

| 指标 | Native | PyPTO |
| --- | ---: | ---: |
| 输出 token IDs | [12095, 13, 3555, 374] | [12095, 13, 3555, 374] |
| ACL Graph execute 次数 | 3 | 3 |
| profiled generate | 143.466 ms | 186.964 ms |
| decode launch 周期中位数 | 26929.080 us | 41171.360 us |
| decode device span 中位数 | 25055.440 us | 39247.060 us |
| 每 replay device task 数 | [443, 443, 443] | [283, 283, 283] |
| trace event 数 | 31340 | 25952 |
| trace JSON 大小 | 6173101 | 5145006 |

PyPTO 相对 Native：profiled generate **+30.32%**，decode launch 周期中位数 **+52.89%**，decode device span 中位数 **+56.64%**。

## 关键结构差异

- Native 每次 replay 有 40 个 `FusedInferAttentionScore`、40 个 KV scatter，以及 attention 的 QKV/O matmul、Q/K norm 与 RoPE 路径。
- PyPTO 每次 replay 将每层 attention 合并为 1 个 `aicore_kernel_mode_0`，共 40 个；同时当前 trace 中每层仍有 1 个 `simpler_aicpu_kernel_exec_*`，共 40 个。
- PyPTO 的 graph model 本体只剩 FFN/残差等 kernel；PyPTO attention 的 AICore/AICPU task 位于独立 stream，因此比较 device span 时已一并纳入。

机器可读的逐 replay 数据和关键 kernel 统计见 `comparison.json`。
