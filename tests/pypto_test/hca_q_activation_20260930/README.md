# Q投影激活复用的三种写法

基线a7a9f314，CANN9.2、NZ2、atomic0、det0，正式第3层权重，128K/B16。
每个候选整包冻结；显式CPU依赖图/编译/加载通过后上卡。同进程ABBA每侧10次真实设备重放。
三组各用自己的同卡基线，不跨组比较绝对值。

参考ops-nn 19614968 `mat_mul_v3/op_kernel/mat_mul_l1_full_load.h:185–229` 的
`MatmulBaseKernelAL1FullLoad`：A常驻L1供多个N块复用。
这是源码策略参考，未证明安装的Native INT8算子为本形状选择了此模板。

## 生成代码决定实际流水

- 整K1024版本的Left由`CompactMode::Null + TMOV`变成`Normal + TEXTRACT`。
  其最初冻结源码注释误写“保留K128”，现明确纠正：原实现与候选的L0均为K256。
  `prepare.py`已更正注释，没有修改已测冻结包的代码。
- 四独立块版本恢复原来的`TMOV`；整数K0→3累加顺序不变。
- N128 stage2实际分配：Mat共384KiB，Left/Right各两个32KiB槽，Acc只有一个64KiB槽。
  不能因为源代码写stage2就宣称L0C也双缓冲；生成核的Acc均复用地址0。
  20个workers、M128/K256、cache policy、任务依赖保持不变。
